# Daily — Habit & Accountability MVP

A standalone browser MVP. No backend is required.

## Run
Open `index.html` in a browser.

Data is stored locally in the browser using localStorage.

## Core flow
Plan → Do → Reflect → Improve

Features:
- Habit creation and daily check-off
- Day rating 1–10
- Good thing / bad thing / lesson / tomorrow priority
- Daily streak
- Calendar
- History
- Basic insights
- Responsive mobile UI

## Production upgrade
Replace localStorage with Supabase Auth + PostgreSQL and add Row Level Security.
